# Football Analytics Service

## Алгоритм работы сервиса

1. Загружает прогнозы моделей из CSV
2. Фильтрует данные по лиге, сезону, датам, модели и размеру выборки
3. Считает вероятностные метрики: Accuracy, Log-Loss, Brier Score, RPS
4. Нормирует букмекерские вероятности и очищает их от маржи
5. Ищет value-ставки по EV и разнице `p_model - p_fair`
6. Симулирует стратегии:
   - Flat
   - Kelly
   - Fractional Kelly
